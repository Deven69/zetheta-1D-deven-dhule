# Incident response playbook

Detect with API audit, Falco, admission events, and mesh telemetry. Triage the
affected namespace, service account, image digest, and Vault lease. Contain by
isolating the workload and revoking credentials. Eradicate by rebuilding from
source, rescanning, signing, and redeploying. Recover gradually with enhanced
monitoring, then record root cause, evidence retention, and control changes.
